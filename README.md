# Rally

Product website for [Rally](https://rally.echoaisms.com) by Echo AI LLC — an AI-native group-buying product for Shopify merchants and everyday organizers.

## Pages

- `index.html` — Landing page
- `privacy.html` — Privacy Policy (`/privacy`)
- `terms.html` — Terms of Service (`/terms`)
- `support.html` — Support (`/support`)

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

Static files only — deploy the repository root to any static host pointed at `rally.echoaisms.com`.
